# Nepal Startup Opportunity Agent

Scheduled Claude Code Remote agent that researches global startup opportunities and evaluates their potential for the Nepal market.

## What it does
- Searches for promising startups across all categories (AI, SaaS, Fintech, EdTech, HealthTech, etc.)
- Evaluates each using the Nepal Scalability & Adoption Framework
- Scores opportunities (0-100 Nepal Opportunity Score)
- Posts daily digest to Slack #startup-ideas

## Schedule
Daily at 9pm Nepal Standard Time (15:15 UTC)
